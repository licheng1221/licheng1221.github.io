# Cheng Li — personal website

Website: https://licheng1221.github.io/
Repository: https://github.com/licheng1221/licheng1221.github.io

## Files

- `index.html`: Home, News and Research.
- `cv.html`: Curriculum Vitae.
- `small-wonders.html`: Photography gallery and NOISE film.
- `styles.css` and `typography.css`: Shared layout, palette and typography.
- `script.js`: Copyright year and the looping gallery.
- `assets/`: Portrait, favicon and photography.
- `.nojekyll`: Serves the static files directly on GitHub Pages.

## Updating the website

This folder is a Git working copy connected to the GitHub repository. Pull remote updates before editing, preview local changes, then commit and push to `main`. GitHub Pages automatically publishes updates from the repository root. Local edits do not go live until uploaded to GitHub.

New photographs go in `assets/photography/`; add corresponding image entries in `small-wonders.html` to include them in the gallery. Preserve the uppercase and lowercase letters in filenames.

The Vimeo player uses the creator's embedding permissions. Email links open the visitor's configured mail app.
